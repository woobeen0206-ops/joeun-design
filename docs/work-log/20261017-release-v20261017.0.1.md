## 이번 업데이트 내용

### 시공사례 화면 정리

- 기존 7개 시공사례를 `작은 사진 선택 → 큰 사진 → 우측 설명` 흐름으로 통일했습니다.
- 사진별로 공간명, 시공 범위, 상담 때 함께 확인할 항목을 보여주도록 구성했습니다.
- 실제 현장에 사용한 제품명이나 품번을 확인하지 못한 사진에는 임의 자재명을 넣지 않고, 현장 기록 확인 후 안내한다는 문구로 구분했습니다.
- 컴퓨터와 휴대폰에서 사진 선택, 공간별 필터, 이전·다음 사진, 원본 확대가 동작하는 것을 확인했습니다.

### 컨셉 사진 · 자재 가이드 추가

- 주방, 거실, 현관, 욕실의 실사형 AI 컨셉 사진 4종을 추가했습니다.
- 사진의 번호를 누르면 자재명, 조합, 선택 이유, 현장 확인 항목을 볼 수 있게 했습니다.
- 모든 컨셉 사진에 `AI 컨셉 이미지 · 실제 시공 사진 아님`을 표시하고, 제안 사양과 공식 확인 자재를 구분했습니다.
- 거실 아트월은 기존 포세린 패널 표현에서 도배 마감으로 변경했습니다.
- 거실 01번에는 공식 제품 정보가 확인된 LX Z:IN 디아망 `린넨 캔버스 / 샌드그레이` `PR056-01`을 표시했습니다. 이미지에는 공식 샘플을 참고한 질감 표현을 사용하며, 실제 시공 전에는 실물 샘플과 조명 아래 색감을 확인해야 합니다.

### 메인 홈페이지 연결

- 상단 메뉴와 모바일 메뉴에 `컨셉 · 자재` 링크를 추가했습니다.
- 시공사례 아래에 거실 컨셉 사진과 안내 문구, 이동 버튼을 넣어 컨셉 자재 가이드로 자연스럽게 이어지도록 했습니다.
- 컨셉 페이지와 실제 시공사례를 혼동하지 않도록 안내 문구를 함께 표시했습니다.
