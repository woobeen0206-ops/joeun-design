# 지금까지의 홈페이지 작업 기록

작성일: 2026-10-12

이 문서는 저장소의 현재 Git 기록과 프로젝트 문서를 기준으로, 좋은디자인 홈페이지가 현재 상태에 이르기까지의 작업을 한 번에 확인할 수 있도록 정리한 첫 기록입니다.

## 현재 상태

- 공개 홈페이지의 원본은 `frontend/public/cases/`에서 관리합니다.
- 홈페이지와 무료 견적 페이지, 사진·음악 자산은 원본 폴더에 있습니다.
- `design-preview/`는 과거 시안과 검토 자료를 보관하는 곳이며 운영 배포 대상이 아닙니다.
- 배포할 파일은 원본에서 `.deploy/site/`로 자동 수집한 뒤 S3와 CloudFront에 반영합니다.
- 관리자 기능과 백엔드는 아직 구현 전이며, 향후 Next.js·Spring Boot·PostgreSQL 구조로 확장할 계획입니다.
- 운영 배포는 GitHub의 `main` 커밋과 릴리스 태그를 먼저 만든 뒤 진행하는 흐름으로 정리되어 있습니다.

## 작업 흐름

1. 홈페이지 원본을 수정합니다.
2. 실제 HTML에서 참조하는 파일만 배포 산출물로 모읍니다.
3. 누락 파일, 빌드와 코드 검사를 실행합니다.
4. 운영 반영이 필요한 경우 GitHub 커밋과 릴리스 태그를 만든 뒤 S3·CloudFront에 올립니다.
5. 공개 주소에서 배포 결과를 확인합니다.

자동 배포는 기존 S3 파일을 지우지 않도록 되어 있습니다. 오래된 파일을 정리하는 일은 별도의 검토와 확인이 필요합니다.

관련 커밋: `adc458e` `Initial commit`

### 2026-10-11 — 현재 홈페이지와 배포 구조 정리

- 운영 홈페이지 원본을 `frontend/public/cases/`로 모았습니다.
- 과거 시안은 `design-preview/`에 보관하고 운영 배포에서 제외했습니다.
- `.deploy/site/`를 유일한 S3 업로드 경계로 정했습니다.
- 변경 파일 목록과 파일 해시를 배포 매니페스트로 남기도록 했습니다.
- 원본 검사, 배포본 생성, 빌드·린트, S3 업로드, CloudFront 캐시 갱신, 공개 파일 확인의 순서를 정리했습니다.
