# 홈페이지 작업 업데이트

- 작업일: 2026-10-17 (서울 기준)
- 상태: 운영 배포 완료

## 시공 사례 흐름

- 메인 화면 바로 다음에 대표 완성 시공 사례의 큰 상세 사진을 배치했습니다.
- 대표 사례에서 사진, 시공 범위, 상담 시 함께 볼 부분, 자재 정보를 한 화면에 보여줍니다.
- 그 아래에 사진별 선택 영역과 완성 시공 사례 모아보기 카드를 배치했습니다.
- 주요 흐름을 시공 사례, 컨셉 이미지, 실제 공정 사진 순서로 정리했습니다.

## 컨셉 이미지 안내

- 인트로와 자재 안내 문구에 베이지 정보 배경을 적용해 읽기 쉽게 정리했습니다.
- 모바일에서는 안내 문구가 위아래로 자연스럽게 이어지도록 했습니다.
- 상호 표기를 `조은 디자인`으로 통일했습니다.

## 운영 기준

- 화면 수정이 끝난 뒤 운영 배포 전에는 미리보기를 먼저 공유합니다.
- 공개 화면의 상호 표기는 띄어쓰기를 포함해 `조은 디자인`으로 사용합니다.

## 확인

- 정적 원본 검사를 통과했습니다.
- 로컬 브라우저에서 대표 사례가 메인 바로 다음에 표시되는 것을 확인했습니다.
- 프로젝트 빌드와 린트가 완료됐습니다. 린트는 기존 이미지 최적화 안내 1건만 있습니다.
- 운영 사이트에서 대표 사례 문구와 `조은 디자인` 표기를 확인했습니다.
