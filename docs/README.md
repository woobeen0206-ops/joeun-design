# 프로젝트 문서 안내

이 폴더는 좋은디자인 홈페이지를 운영하고 개선하면서 사람이 읽기 쉽게 남기는 기록을 관리합니다.

## 폴더 구성

| 폴더 | 용도 | 작성 시점 |
|---|---|---|
| `work-log/` | 실제 작업의 목적, 변경 내용, 확인 결과 | 작업 단위가 끝날 때 |
| `decisions/` | 디자인·제품·운영 방식처럼 오래 유지할 결정 | 결정이 확정될 때 |
| `operations/` | 배포, 백업, 점검 등 운영 절차 | 절차가 생기거나 바뀔 때 |
| `design/` | 페이지 구조, 콘텐츠 원칙, 디자인 참고 | 화면·콘텐츠 방향이 정해질 때 |

기술 계약과 Codex가 작업을 재개할 때 필요한 내부 지침은 기존 위치를 유지합니다.

- `.codex/docs/api.md`: 프론트엔드와 백엔드 사이의 API 계약
- `.codex/docs/decisions.md`: 개발 환경과 배포 구조에 관한 기술 결정
- `AGENTS.md`: 프로젝트 전체 작업 규칙

새 작업 기록은 `work-log/YYYY-MM-DD-짧은-제목.md` 형식으로 만들고, 문서 안에 관련 커밋이나 확인 방법을 적습니다. 공개 고객 정보, 비밀번호, 운영 비밀값은 기록하지 않습니다.
