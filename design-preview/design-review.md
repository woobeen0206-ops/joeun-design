# 정적 시안 개선안

참고: 원본 joeun-design-studio.html / 한샘 https://store.hanssem.com/interior

## 가져갈 것
- 실제 대야미동 현장 사진, 차분한 녹색, 설계·설비·철거의 서비스 범위.
- 사진 확대 보기와 시공 전후 기록.
- 한샘의 큰 메인 사진, 공간별 바로가기, 눈에 잘 띄는 상담 동선.

## 바꿀 것
- 사진이 없는 첫 화면 → 실제 거실 사진을 넓게 배치. 짧은 한국어 제목과 상담 연결.
- 설명과 서비스가 먼저 나오는 순서 → 실제 시공 사례 먼저.
- 사진 없는 예시 현장 4개와 빈 카테고리 제거. 한 아파트의 여러 공간을 묶어서 소개.
- 만족도 98%, 120+ 등 근거 미확인 숫자 제외.
- 전후 슬라이더 6개 → 접어서 확인하는 거실 사진 한 쌍. 촬영 각도가 달라 좌우로 비교.
- 원본 주방 전후 사진은 동일. 욕실로 표기된 일부 사진은 현관처럼 보여 그대로 사용하지 않음.
- 공정 소개의 4단계/5개 카드 불일치 수정. 상담 → 디자인·견적 → 철거·시공 → 점검·사후관리.
- 흐르는 문구 띠, 반복 설명, 외부 Formspree 폼 제거. 전화·이메일 문의로 단순화.
- 키보드 사진 이동, Escape 닫기, 초점 복귀, 모바일 메뉴와 하단 상담 버튼.

## 디자인
한샘의 사진 중심 구성을 소규모 시공 포트폴리오에 맞춰 간소화했다.
아이보리·짙은 녹색과 정돈된 사진 그리드. 메인 사진은 수동 넘김.
한샘의 사진·로고·상품·후기는 복사하지 않았다.
이미지는 원본 그대로이며 전체 시안을 HTML 한 파일로 열 수 있다.

## 공개 전 확인
상호(프로젝트 지침은 좋은디자인, 원본은 조은 디자인), 전화·이메일·주소·영업시간,
현장 정보와 사진 공개 동의, 제안 문구·서비스·사후관리 범위.
평형과 금액은 미확인이므로 임의 작성하지 않았다.
현재 사진은 다소 어둡고 공사 흔적이 있어 준공 청소 후 밝은 시간대의 재촬영을 추천한다.

원본 변경 및 외부 배포 없음. 관리자와 상담 접수 서버는 이번 정적 시안에 포함되지 않는다.

# 시안 2 — 간편 상담 플로우

파일: `joeun-design-estimate.html`

하이픈디자인 견적 페이지에서 가져온 것은 큰 브랜드 문구나 사진이 아니라, 방문자가 곧바로 선택을 시작하는 **단계형 상담 흐름**이다. 한 화면에 질문 하나만 두고, 하단 버튼으로 다음 단계로 넘긴다.

- 첫 화면부터 `어떤 도움이 필요하세요?`를 묻는다. 포트폴리오 탐색보다 문의 전환이 목적일 때 적합하다.
- 서비스, 공간 유형, 희망 시기, 상담 방법을 4단계로 받는다.
- 마지막 결과에서 선택 내용만 요약한다. 이 시안은 실제로 번호를 전송하거나 상담을 접수하지 않는다.
- 모바일 하단의 큰 다음 버튼, 16px 이상 본문 텍스트, 한 손으로 누를 수 있는 큰 선택지를 우선으로 설계했다.
- 원본 현장 사진 하나만 사용했으며, 하이픈의 로고·사진·문구·브랜드 요소는 사용하지 않았다.

## 두 시안의 역할

| 시안 | 어울리는 목적 | 첫 화면에서 하는 일 |
|---|---|---|
| `joeun-design-refined.html` | 시공 실력과 분위기를 보여주기 | 대표 현장 사진을 보고 포트폴리오 탐색 |
| `joeun-design-estimate.html` | 광고·검색 유입을 상담으로 연결하기 | 필요한 공사를 선택하고 상담 준비 |

실제 홈페이지에서는 첫 번째를 메인으로 두고, `상담 문의` 버튼이 두 번째 흐름으로 이어지게 만드는 구성이 가장 자연스럽다.

# 시안 3 — 하이픈 메인형

파일: `joeun-design-hyphen-main.html`

하이픈디자인 메인에서 참고한 것은 **큰 브랜드 문장 → 대표 사례 → 작업 기준 → 상담 전환**의 흐름이다. 하이픈의 사진·로고·문구는 사용하지 않았다.

- 첫 화면은 짧고 큰 문장과 실제 시공 사진을 절반씩 배치했다.
- 사례를 방 종류로만 나누지 않고 `생활`, `동선과 수납`, `기초 공정`이라는 이야기로 묶었다.
- 후기나 시공 건수처럼 확인되지 않은 정보는 넣지 않았다.
- 모바일에서는 사진과 문장이 세로로 이어지고, 화면 하단의 `시공 사례 / 간편 견적` 버튼을 계속 사용할 수 있다.
- `무료 견적` 버튼은 시안 2의 단계형 상담 화면으로 연결된다.

## 현재 추천 조합

메인 페이지는 시안 3의 브랜드 구조가 가장 강하다. 실제 개발에서는 시안 3을 메인으로 쓰고, 사진 목록과 상세 갤러리는 시안 1의 탐색 방식을 섞은 뒤, 상담 버튼을 시안 2로 연결하는 구성을 추천한다.
