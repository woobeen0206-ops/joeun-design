# 현 작업 인수 및 다음 구현 기준

## 확인한 변경

- 최신 검토 대상은 `frontend/public/cases/index.html`이다. 기존 `/` React 메인과는 별개의 정적 페이지다.
- 7개 사례, 사례별 사진 갤러리, 사례 02·07의 전후 비교, 공정 8종, 대표 이미지 4장으로 확장됐다.
- 새 공개 자산은 `frontend/public/cases/projects-assets/`에 있으며 사례 번호로 익명화했다. 원본 사진의 폴더명은 공개 데이터로 이관하지 않는다.
- 새 시안은 상호를 `조은 디자인`으로 표기한다. 기존 앱/지침의 `좋은디자인`과 달라 운영 전 확정이 필요하다.
- Git 저장소가 아니므로 정확한 작성자별 diff는 알 수 없다. 이전 대화와 현 파일을 비교해 파악했다.

## 이번 인수에서 수정

- 정적 견적 페이지의 존재하지 않는 복귀 링크를 `index.html`로 수정했다.
- 정적 견적 페이지의 누락된 사진 경로를 기존 사례 02 파우더룸 사진으로 연결했다.

## 남은 개발 순서

1. 최신 정적 시안의 CASES / ONSITE / HERO 데이터를 React에서 재사용하는 구조로 옮기고 기존 메인과 통합한다. 익명 사례 번호와 사진 순서를 보존한다.
2. 사례 목록 및 개별 상세 주소, 키보드 접근 가능한 사진 갤러리를 구현한다.
3. 현재 Vinext/Cloudflare 기반 실행 구조와 원래 Next.js/Spring/VPS 계획을 정리한다. 현재 실행기가 정식 Next.js 서버라는 전제로 진행하지 않는다.
4. API 계약 확정 후 Spring/PostgreSQL 관리자 로그인, 사례 편집, 사진 업로드·순서·대표 사진·공개 상태를 구현한다.
5. 이미지 리사이즈/WebP 및 메타데이터 제거, 모바일 확인, 배포/백업 준비를 진행한다.

## 아직 완료되지 않은 항목

- DB와 관리자 API는 미구현이다. 상담 화면은 선택 내용을 요약할 뿐 접수/알림을 보내지 않는다.
- 이전 대화의 모바일/사진 확대 검증 완료 주장은 기록상 충분한 근거가 없다. 통합 후 실제 검증이 필요하다.
- 이미지 공개 동의, 상호/연락처, 실제 서비스 범위는 운영 공개 전 확인한다.
