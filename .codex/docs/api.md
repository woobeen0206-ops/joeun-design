# API 계약

현재 API는 미구현이며 구체적인 경로·요청·응답은 아직 확정하지 않았다.
구현 전에 이 문서에 계약을 작성하고 FE/BE가 동일한 계약을 따른다.

## 공통 원칙

- 공개 조회: `/api/public/**`, 공개된 시공 사례와 사진만 반환.
- 관리자: `/api/admin/**`, 세션 인증 필수. 로그인 진입점과 CSRF 토큰 발급 경로는 구현 전에 별도로 정한다.
- 브라우저는 같은 도메인의 `/api/**`로 요청한다.
- 세션 쿠키는 HttpOnly, 운영 HTTPS에서는 Secure. CSRF 보호를 유지한다.
- 에러 응답은 `code`, `message`를 포함한다.

## 구현 전에 확정할 항목

- 로그인·로그아웃·세션 확인 및 CSRF 토큰 전달 방식
- 시공 사례 목록·상세·등록·수정·삭제·공개 전환
- 사진 업로드·순서 변경·대표 사진·삭제
- 각 API의 메서드, 경로, 인증, 요청/응답 예시, 상태 코드
- 페이지네이션, 정렬, 날짜 형식, 업로드 제한

## 변경 절차

메인 Codex가 공유 문서 작성자를 정한다. FE는 필요한 변경을 제안하고,
계약 확정 후 BE 구현과 FE 연결을 진행한다. 제안과 확정 사항은 구분한다.
