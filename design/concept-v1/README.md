# 청담 엔터테인먼트 오피스 콘셉트 V1

이 초안은 사용자가 제공한 인쇄 평면도, 손도면 2장, 철거 현장 영상(IMG_6490.mov)을 비교해 만든 공간 구성 검토안이다.

## 적용 기준

- 용도: 엔터테인먼트 회사 사무실
- 방향: 프라이빗 갤러리형 오피스
- 천장: 기준 높이 2,400mm, 오픈 천장, 기존 설비와 배선 정리
- 현관 기준 왼쪽 벽: 기존 검은 프레임 통유리 벽으로 해석
- 출입구 우측 기존 유리 파티션 방: 대표실
- 대표실 오른쪽 끝 코너: 화장실과 창고
- 외곽 창호: 영상에서 확인된 연속 창호와 코너 창을 채광 요소로 활용
- 설비 구역: 노란 가스관, 급배수관, 수직 배관이 집중된 기존 위치를 탕비·설비 공간으로 활용

## 공간 구성

- 리셉션과 대기 라운지
- 아티스트·콘텐츠 갤러리 동선
- 직원 오픈 업무공간 8~12석 가정
- 출입구 우측 유리 파티션 대표실
- 6~8인 회의·오디션실
- 화상회의·통화 부스
- 탕비실
- 오른쪽 끝 코너의 화장실과 창고

## 정확도

손도면에서 비교적 분명한 전체 길이 14,540mm와 주요 부분 치수를 우선 적용했다. 흐릿하거나 기준점이 불분명한 수치는 `약`으로 표시했다. 이 파일은 배치와 디자인 방향을 검토하는 초안이며 시공용 도면이 아니다. 시공 전에는 보·기둥, 문·창호, 배관 중심선, 바닥 단차를 현장에서 다시 실측해야 한다.
